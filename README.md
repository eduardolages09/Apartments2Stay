# Apartments2Stay

Site da Apartments2Stay, gestora de alojamento local no centro histórico do Porto: uma página de entrada com todas as casas
e uma página própria para três delas.
Site estático (HTML, CSS e JS, sem build): abre `site/index.html` ou publica a pasta `site/`.

- `site/index.html` — a página de entrada: o Porto, a barra de reservas, o catálogo das casas e o mapa.
- `site/discovery/`, `site/casas-do-patio/` e `site/flores/` — a página de cada casa.
- `site/assets/` — estilos, scripts e fotografias.
- `netlify.toml` — publica só a pasta `site/`.

Fotografias da região: Wikimedia Commons (créditos no rodapé do site). Mapas: © colaboradores do OpenStreetMap.
